# Screenshots

Captured from the production build in headless Chromium 153 by the harness in `frontend/qa/`.

**Important:** these screens show the real frontend running against **fixture data** (`frontend/qa/fixtures.js`), because no Spring backend or Supabase project was available during QA. The numbers, names and tasks are sample data, not output from the real API. The dashboard figures are computed consistently from the fixture tasks, but that checks the UI, not the backend aggregates.

The complete matrix (every page, light and dark, at 1440, 1280, 1024, 768, 390 and 360 px) can be regenerated with `npm run qa` in `frontend/` (see `frontend/qa/README.md`).
