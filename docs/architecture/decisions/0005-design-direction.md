# ADR 0005: Visual direction

Spruce green and amber on a cool off-white (light) or deep forest-black (dark). Bricolage Grotesque for headings, Public Sans for text, both self-hosted through Fontsource (no third-party font requests). Motion is limited to one orchestrated hero moment, the status beam fill, and responses to user action (modals, drawer, toasts). The theme is a token system, not per-component overrides. Details: [design-system.md](../../design-system.md).
